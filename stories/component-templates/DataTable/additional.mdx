## Multi-select row select event

When `multiSelect` is enabled, the `sgds-row-select` event is emitted each time a row checkbox changes.
The event detail contains a `selected` array of objects, where each key is derived from the header text (or `sortKey` if set).

## Header and cell props

Use `sorting`, `sortKey`, `width`, and `textAlign` on header cells.
This example keeps all cells unmerged to show a standard sortable fixed-layout table.

Only headers with `sorting` participate in sort interactions.
When the sort direction cycles back to `none`, client-mode rows return to their initial slotted order.

## Sort event (server mode)

When `serverSort` is enabled, the component's built-in client-side sorting is disabled.
Clicking a sort header only emits the `sgds-sort` event — the actual sorting must be handled by your API.
Listen for `sgds-sort`, pass `detail.key` and `detail.direction` to your API request, then replace the table rows with the sorted response.

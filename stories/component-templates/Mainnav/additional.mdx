## Fluid

By default, the Mainnav content is contained within a max-width container. Use the `fluid` prop to remove this constraint and allow the content to stretch to the full screen width.

- Use `fluid` mainnav when you need the navigation bar to span the full viewport width.

## Profile Slot

Use `sgds-mainnav-profile` in the `profile` slot to render a user profile dropdown. It displays an avatar, label, and secondary text in desktop, and collapses into an avatar toggler with a mobile panel in smaller viewports.

- The `label` and `secondaryText` props control the text displayed beside the avatar in desktop.
- Use `readonly` on the first `sgds-dropdown-item` for non-interactive account info.
- Use `sgds-divider` to separate item groups within the dropdown.
- Set `close="outside"` to prevent the menu from closing when clicking inside it.
- The hamburger toggler is always rendered alongside the profile — both menus work independently.

## Tone

The `tone` prop controls the visual theme of the navigation bar. There is no white/default tone — the minimum is `brand`. All tones render text and icons in fixed-light (white).

### Brand

Uses the primary surface colour as the background. This is the default.

## With Profile

Use `sgds-appnav-profile` in the `profile` slot for user account menus. It displays avatar + label + secondary text in desktop, and collapses into an avatar toggler with a self-contained mobile panel in smaller viewports.

- The three-dots toggler appears to the left of the profile when the default slot has items.
- In mobile, icon-buttons collapse into text menu items (using their `ariaLabel`).
- The profile has its own independent mobile panel.

## No Default Slot Items

When no icon-buttons are placed in the default slot, the three-dots toggler does not render. Only the start slot, brand, and profile are visible.
